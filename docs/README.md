# Documentation Map

This directory contains public reference documentation, LLM-agent runbooks, and generated GitHub Pages output. Use this map to find the right source and avoid editing generated files.

## For Readers and Contributors

| Document | Purpose | Edit directly? |
|---|---|---|
| [`../README.md`](../README.md) | Catalog overview, scope, curation policy, and paper tables | Generated from catalog data; use the generator |
| [`../CONTRIBUTING.md`](../CONTRIBUTING.md) | Contribution rules and local validation commands | Yes |
| [`taxonomy.md`](taxonomy.md) | Threat, failure, risk, section, and subsection semantics | Yes |
| [`taxonomy.ja.md`](taxonomy.ja.md) | Japanese translation of the taxonomy | Yes; keep aligned with the English source |
| [`metadata-schema.md`](metadata-schema.md) | Catalog record and optional extension semantics | Yes |
| [`visualizations.md`](visualizations.md) | Explanation of the generated research-landscape views | Yes |

## For LLM Agents and Automation Maintainers

Start with [`../AGENTS.md`](../AGENTS.md). It routes recurring work to the applicable runbook:

- [`agent/daily-curation-workflow.md`](agent/daily-curation-workflow.md): discovery, curation, generation, validation, and publication.
- [`agent/biweekly-metadata-maintenance.md`](agent/biweekly-metadata-maintenance.md): targeted venue, code, bibliography, and secondary-defense maintenance.

These runbooks are public operational documentation. Local schedules should keep machine-specific paths, cadence, and private workspace boundaries in the automation prompt rather than adding them here.

## Generated GitHub Pages Output

Do not hand-edit these files:

- `index.html`: interactive Project Page, generated by `scripts/build_explorer.py`
- `readme.html`, `readme.ja.html`, `taxonomy.html`, `taxonomy.ja.html`: rendered Markdown pages, generated by `scripts/build_doc_pages.py`
- `visualizations/*.svg`: generated charts, produced by `scripts/build_visualizations.py`
- `robots.txt`, `sitemap.xml`, and the search-engine verification file: deployment assets

The explorer source template lives outside this directory at [`../templates/explorer.html`](../templates/explorer.html). Keeping source templates outside the Pages output makes the edit boundary explicit.
